## 2026-11-24 地质纸偶剧场

- 用 Node.js 24.22.3 对新锁文件做独立离线安装及生产构建。项目 TypeScript、ESLint、生产构建通过。真实 PostgreSQL 18.7 的 4 项后端测试全部运行，临时测试库和界面预览库各自从 34 条种子初始化。预览库公开 8 条。
- Edge 中先用固定的首页记录走通桌面、手机两种宽度下的主题选择、筛选列表和原始出处。再用生产构建逐项比对真实接口，3 个主题、8 个发布月份和 2 个地区的图上条数与相应文献列表全部相符。触屏模拟在「三亚·海南」范围点选「跨境资金」得到 4 条。共 13 项端到端测试覆盖数量表、拖动、键盘、点光、暂停记忆、来源、发布归档、导入和审计。单主题、缺失发布日期和大样本矿粒余量另以固定样本覆盖。
- 对首页、文献库、详情、数据分析、维护登录和维护目录各检查 320、390、740、741、768、1020、1021、1440 CSS px，共 48 组均无页面横向溢出。390px 和 1440px 的 12 次 axe WCAG 2/2.1 A、AA 扫描为零违规。实际纠正了移动题名签的留白和控件的可访问名称。连续点击、键盘激活、触屏、减弱动效和会话暂停均有单独检查。
- 在移动网络与 CPU 限速下复现了文库和分析页加载时的页脚跳动。PerformanceObserver 将 CLS 0.15758 定位到移出视口的页脚，为目录页的标题与主体预留首屏后，两页各复测三轮均为 0。移动端测量使用 Edge 390×844，150ms RTT、1.6Mbps 下行、4× CPU、暖缓存。点击至第二次绘制回调的耗时作为交互样本记录，真实设备体验需实机复核。
- 最终构建中，首页、分析、文库三轮暖缓存 LCP 中位数分别为 760、796、800ms，九次采样的 CLS 均为 0。点击至第二次绘制回调的九次样本为 30–180ms。六个视图未捕获控制台错误。桌面与手机截图、12.8 秒实录 MP4、逐组数据对照及移动端采样保存在本机 [地质纸偶剧场验收目录](../../地质纸偶剧场-验收/)。此次交付在本机运行，下方公网记录对应先前发布版本。

### 浅色沉积背景

- 类型检查、ESLint、生产构建与 17 项端到端测试全部通过。新增测试在正常浏览器时钟下检查细纹前移和沉积夹层错时伸展，并比较六道层界在不同动画进度下的屏幕坐标。另覆盖手机搜索、跨页暂停和恢复、标签页可见性与系统减少动态。
- 在 Edge 1440×900 和 390×844 模拟视口各录取两张间隔三秒的首页帧。扣除前景矿样，两种尺寸均能观察到层内细线和夹层尖端发生位移。两个尺寸各检查首页、文献库、分析和维护登录，八次文字对比度扫描均为零违规。320、390 和 1440px 首页均未出现页面横向溢出。[正常速度的 14 秒本地实录](../../地质纸偶剧场-验收/地脉演变实录.mp4)
- 静态纸纹和活动细线分层绘制后，使用 390×844、DPR 1 的无头 Edge 独立比较背景开启和暂停。保留前景矿样动画，交错取样，正常 CPU 下两组帧间隔中位数均为 16.7ms、P95 均为 16.8ms。四倍 CPU 限速时两组均出现超过 50ms 的间隔，低配手机的流畅度仍待真机核对。
