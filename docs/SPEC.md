# 实现规格与旧能力迁移

使用者为课程评审、访客及小组维护员。访客从政策专题进入搜索或图表，定位有公开出处的单条证据。维护员从有限官方来源采集元数据，补写摘录或摘要并核验，再提交到同一数据库。

| Vue 旧能力 | React 对应 | 验收 |
| --- | --- | --- |
| 首页、进入原资料库 | 首页与文献库 | 跨境资金专题能打开带筛选的列表 |
| 资料库、检索与关键词浏览 | 文献库 URL 筛选与独立详情 | 中文命中、分享深链接、引用可打开 |
| Dashboard、Analysis | 文献数据分析 | 趋势、地区和主题统计与结果集对照 |
| Intake、Admin | 采集管理 | 采集预览、草稿、发布、归档、审计 |
| 指南、报告 | 仓库文档及个体报告 | 可复现运行、部署和答辩 |
| 地图、图谱、风险评级、Copilot | 旧项目基线提供历史演示 | 从 README 回到旧项目源码 |

界面沿用冷白阅读背景、墨蓝视觉层级和矿铜交互强调。宽屏文献库提供筛选栏、文献列表和证据预览。窄屏用抽屉筛选及独立详情。图表筛选同时提供可点击的文字入口。维护员可用键盘完成表单填报，动态效果受系统偏好控制。

旧记录迁移优先保留原标识和可追溯的来源。公开页使用实际已发布记录。服务响应失败显示明确的错误和重试入口。上线采用 HTTPS 同源，允许免费选项及路径回退。覆盖课程正式 Word 与群聊的截止信息。提交前由组长按校历确认第 16 周周五所在日期。
