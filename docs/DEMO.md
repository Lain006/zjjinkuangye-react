# 答辩流程和个人报告材料

## 现场流程

1. 无痕窗口打开公网首页，点击跨境资金专题，展示筛选后的公开资料和原始出处。
2. 维护员在另一窗口打开「采集管理」，选择三亚跨境资金集中运营中心政企对接座谈会。核对原文标题、发布日期、来源与内容口径。打开采集预览，补写小组摘要，保存草稿后发布。
3. 用无痕窗口检索同一标题，打开详情，核对发布机构和来源。用分析页选择月份或主题，点回含该记录的列表。
4. 在浏览器打开公网 JSON 查询接口。在 DBeaver 用只读角色查询刚发布的文献 ID 和操作记录。答辩前完成真实网络和冷状态练习。
5. 采集来源临时受阻时，保留手动录入展示路径，写明采集情况。需要第二次彩排时使用另一条尚未入库的预配置来源或独立排练数据库。

## 每位组员需填写

拿到老师正式模板后，将以下材料填入对应章节，并按课堂指定方式分别提交。

- 个人分工和可核对的提交记录。
- 实现机制、核心页面截图和本人解决的问题。
- 测试输入、步骤与结果，包含一个失败路径。
- GitHub、前端、后端三个地址，及 DBeaver 实际查询截图。
- 当前交付限制与小组协作贡献。带姓名、学号的提交稿单独保存。

## 提交周核对

如本班采用三亚学院教务处发布的 2026–2027 学年秋季校历，第 16 周为 2026 年 12 月 28 日至 2027 年 1 月 3 日，周五为 2027 年 1 月 1 日。个人报告提交时间及元旦安排以老师群通知为准。 [教务处校历](https://jw.sanyau.edu.cn/2026/0509/c1970a451991/page.htm)

## 批量导入旧资料

进入采集管理，点击「批量导入」并选择旧版导出的 Excel（.xlsx 或 .xls）、UTF-8 CSV 或 JSON 数组。Excel 读取第一个工作表。每批最多 100 条、原文件最多 2 MB。表格首行至少包含字段名 `title,sourceName,sourceUrl,sourceType,region,category`，也可使用对应中文列名。旧版 `collectDate` 会映射为采集时间，发布日期留空时保留为空。

确认后，新记录作为草稿写入 PostgreSQL。重复来源链接会跳过，格式无效的批次会提示记录序号并保持整批未写入。旧版 ID、风险模型字段和发布状态不会用来覆盖现有资料。到资料目录筛选「草稿」，核对来源后发布。
